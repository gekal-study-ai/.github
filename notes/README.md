# 学習ノート

[ROADMAP.md](../ROADMAP.md) の各フェーズで作るノートを置きます。

## 書き方

長文にしないこと。次の 3 点が書いてあれば十分です。

- **試したこと**
- **結果**（数値があれば必ず入れる）
- **次にやること**
